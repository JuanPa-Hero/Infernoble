# Infernoble Knight - Renaud Card Binder

Checklist independiente basada en la app Gouki/D.D. para registrar cartas Infernoble Knight y cartas de apoyo.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo, por ejemplo `infernoble-knight-renaud-binder`.
2. Sube `index.html` y `README.md` a la raíz de `main`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, `main` y `/ (root)`.
4. Abre la URL que GitHub Pages te muestre.

Las marcas y cartas personalizadas se guardan localmente en el navegador. Exporta un respaldo para conservar tu colección.

Nota: el catálogo es una base inicial; verifica nombres y cartas relacionadas en la base oficial antes de usarlo como inventario exhaustivo.
